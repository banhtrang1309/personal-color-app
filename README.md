# Personal Color App

An Android application that helps users identify their personal color palette through AI-powered image analysis.

## Overview

Personal Color App is an Android application developed using Kotlin and Jetpack Compose. The application analyzes facial and skin-tone information from captured images and provides personalized color recommendations using Google Gemini AI.

User accounts and analysis history are managed through Firebase services, allowing users to save and review previous results.

## Features

* User authentication
* Image capture with CameraX
* AI-powered personal color analysis
* Personalized color recommendations
* Analysis history management
* Modern UI built with Jetpack Compose

## Getting Started

### Prerequisites

* Android Studio
* Android SDK
* Firebase Project
* Gemini API Key

### Installation

```bash
git clone https://github.com/banhtrang1309/personal-color-app.git
```

1. Open the project in Android Studio
2. Configure Firebase credentials
3. Configure Gemini API Key
4. Build and run the application
